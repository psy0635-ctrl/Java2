과제1 - 간단한 메모장 메뉴 및 기능 업데이트

학과: 인공지능소프트웨어학과
학번: 2601110288
이름: 박수용
패키지 / 클래스: ai1103 / MenuTest_Project

1. 과제 목적
11월 3일 수업에서 작성한 메모장 프로그램을 바탕으로 메뉴 항목과 기능을 수정하였습니다. 기존 프로그램은 새 문서를 만들고 파일을 여는 기능은 있었지만, 작성한 내용을 저장하는 기능은 없었습니다. 따라서 File 메뉴에 Save와 Save As를 추가하였습니다.

2. 추가 및 수정한 기능

(1) Save 추가
작성한 내용을 UTF-8 형식의 텍스트 파일로 저장하도록 하였습니다. 처음 저장하는 문서는 저장 위치와 파일명을 선택합니다. 이미 열었거나 저장한 문서는 같은 경로에 다시 저장합니다. 저장이 끝나면 창 제목에 파일명이 표시됩니다.

(2) Save As 추가
현재 문서를 다른 이름이나 위치로 저장할 수 있도록 하였습니다. 저장할 파일명이 .txt로 끝나지 않으면 .txt를 붙입니다. 저장 창에서 선택한 경로에 같은 이름의 파일이 있으면 덮어쓸지 확인합니다. Save As에 성공하면 이후 Save는 새 경로에 저장합니다.

(3) New, Open, Close 보완
마지막으로 열었거나 저장한 내용과 현재 내용을 비교하도록 하였습니다. 내용이 달라진 상태에서 New, Open, Close를 선택하면 저장 여부를 묻습니다. '예'를 선택하면 저장이 끝난 후 작업을 진행하고, '아니요'를 선택하면 저장하지 않고 진행합니다. '취소'를 선택하거나 확인 창을 닫으면 현재 문서를 유지합니다. 저장 창을 취소하거나 저장에 실패했을 때도 다음 작업을 진행하지 않습니다. 창 오른쪽 위의 X 버튼에도 같은 종료 처리를 연결하였습니다.

(4) 기존 메뉴와 도구 모음 유지
New는 새 문서를 만들고, Open은 UTF-8 텍스트 파일을 열며, Close는 메모장 창을 닫습니다. 도구 모음의 세 아이콘에도 각각 같은 기능을 연결하였습니다. Edit의 White, Blue, Magenta와 색상 버튼은 입력 영역의 배경색을 바꿉니다. 파란색 배경에서는 글자를 흰색으로 표시하고, 나머지 배경에서는 검은색으로 표시합니다.

3. 수정 과정
먼저 기존 메뉴와 버튼에 연결된 이벤트 처리 코드를 확인하였습니다. 이후 Save와 Save As 항목을 File 메뉴에 추가하고, 기존 File 이벤트 처리 부분에서 저장 메서드를 호출하도록 연결하였습니다.

현재 파일의 경로는 currentFile에 보관하고, 마지막으로 열었거나 저장한 내용은 savedText에 보관하도록 하였습니다. 저장 기능은 saveFile 메서드로 묶어 Save, Save As, 저장 여부 확인에서 함께 사용하도록 하였습니다. 파일을 열 때는 읽기에 성공한 뒤에만 입력 영역과 현재 경로를 변경하도록 하였습니다.

첨부된 아이콘 세 장은 new.png, open.png, close.png로 파일명을 맞추고 toolbar 폴더에 배치하였습니다. 버튼에서는 32×32 크기로 표시하도록 하였습니다. 아이콘 경로는 toolbar/new.png, toolbar/open.png, toolbar/close.png로 지정하였습니다. 현재 프로젝트에서는 C:\study\Java2를 실행 작업 폴더로 사용하고, 그 아래의 toolbar 폴더에서 이미지를 불러오도록 하였습니다. 이미지를 찾지 못하면 버튼에 기능 이름을 표시하도록 하였습니다.

4. 구현 과정에서 주의한 점
저장 기능에서는 저장 성공과 취소를 구분하는 처리가 필요하였습니다. 저장 확인 후 곧바로 문서를 지우거나 창을 닫으면, 실제 저장을 취소했을 때도 내용이 사라질 수 있기 때문입니다. 이를 방지하기 위해 저장에 성공했을 때만 true를 반환하고, 취소하거나 오류가 발생하면 false를 반환하도록 하였습니다.

한글을 저장하고 다시 열 때 인코딩이 달라지지 않도록 읽기와 쓰기 모두 UTF-8을 사용하였습니다. 또한 이미지 경로가 맞지 않으면 아이콘이 표시되지 않으므로, 코드에서 사용하는 파일명과 제출 폴더의 파일명을 일치시켰습니다.

5. 실행 확인
프로그램을 실행한 뒤 한글을 입력하여 Save로 저장하고, New로 문서를 비운 다음 Open으로 저장한 내용을 다시 여는 과정을 확인하였습니다. 문장을 수정한 뒤 Save로 기존 파일을 갱신하고, Save As로 다른 이름의 파일을 만드는 동작도 확인하였습니다.

내용을 수정한 상태에서 종료를 선택하고 저장 확인 창에서 취소했을 때, 창과 입력 내용이 유지되는 것을 확인하였습니다. 배경색 메뉴와 버튼을 눌러 색상 변경을 확인하였고, 도구 모음의 아이콘 표시와 연결된 기능도 확인하였습니다.

6. 기능 범위
이 프로그램은 UTF-8 일반 텍스트 파일을 대상으로 합니다. 글자 내용은 저장하지만, 배경색과 글자색은 텍스트 파일에 저장하지 않습니다. UTF-8이 아닌 파일은 정상적으로 열리지 않을 수 있습니다.
